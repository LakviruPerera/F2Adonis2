# Contributing to F2Adonis2

Thanks for your interest in F2Adonis2.

## Questions and support

Open an issue at https://github.com/LakviruPerera/F2Adonis2/issues. I will reply as soon as I can, usually within a week or two.

## Reporting a bug

Please include a minimal reproducible example, the output of `sessionInfo()`, and what you expected to happen.

## Suggesting a change

Open an issue describing the problem first, so we can agree on an approach before you write any code.

## Pull requests

1. Fork the repository and create a branch for your change.
2. Add or update tests in `tests/testthat/`.
3. Run `devtools::check()` and make sure it passes.
4. Add a short bullet to `NEWS.md`.
5. Open a pull request that references the related issue.

## Conduct

Please be respectful and constructive in all discussions.
